Engine files used by the Chess page (../index.html) for in-browser analysis.

- stockfish-19-lite-single.js / .wasm : Stockfish.js 19.0.1 (lite, single-threaded) by Nathan Rugg, a WebAssembly build of Stockfish 19.
  Source and licence: https://github.com/nmrugg/stockfish.js and https://github.com/official-stockfish/Stockfish , GPL-3.0 (Copying-GPL-3.0.txt).
  Obtained unmodified from the npm package "stockfish@19.0.1".
- chess.mjs : chess.js 1.4.0 (ESM build, BSD-2-Clause), https://github.com/jhlywa/chess.js , used to convert moves to positions.
