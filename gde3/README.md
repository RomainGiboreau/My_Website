# GDE map generator v3, core (step 1: no UI)

Pure ES modules in `src/` (key lines to proximal-distal field d, belts on d, minimum-change calibration on wells, bounded warping, per-well verdict); systems are data in `src/systems.mjs`. Tests: `node scripts/gde3_test.mjs`; old vs new numbers: `node gde3/tools/compare_old.mjs`.

## Acceptance well sets (map 100 x 100 km, transport azimuth 0 = towards +y, scale 60 km, seed 7)

Well 3 of each set sits beyond the prior limit of its belt (position 1.1-1.2 of the belt), so a boundary has to move: this is the sensitive well that is moved in the stability tests.

| Set | Wells (x, y in m, environment) |
|---|---|
| A. Shoreface-shelf, straight shoreline (the same set shows the instability of the old tool, see below) | W1 50000, 15429 Coastal plain; W2 30000, 24429 Shoreface; W3 65000, 34800 Offshore transition; W4 40000, 46286 Offshore shelf; W5 55000, 63857 Slope |
| B. Wave-dominated delta, lobate shoreline (wobble 2 %, lobe 8 %) | W1 50000, 28488 Delta plain; W2 35000, 36275 Delta front; W3 65000, 47310 Prodelta; W4 45000, 58377 Shelf; W5 55000, 70907 Slope |
| C. Rimmed carbonate platform, straight margin | W1 50000, 13404 Tidal flat / sabkha; W2 35000, 35532 Platform interior / lagoon; W3 65000, 61915 Open platform / back-reef; W4 45000, 62766 Platform margin (reef / shoal); W5 55000, 65745 Fore-reef slope |

(Coordinates are generated by `tools/acceptance.mjs` from the belt position, they are listed here for reference.)

| | old core | v3 |

| Set C, same | 10.0 % | 3.3 % |
| Set B, same | not comparable (old delta is radial) | 5.1 % |
| Sweep +-4 % in steps of 0.1 %, worst step, set A / C | 6.7 % / 3.3 % | 1.7 % / 1.7 % |
| Old tool, 5 wells on a shelf, W1 moved by 0.5 % of the width (coastal plain well) | 11.7 % in one step (first boundary 13714 to 25250 m) | 1.7 % (13800 to 14300 m) |
